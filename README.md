# 🎓 Graduation Website - Nguyễn Hồng Quân

Đây là dự án website cá nhân được thiết kế dành riêng cho Lễ tốt nghiệp chuyên ngành Luật Kinh tế tại Học viện Chính sách và Phát triển (APD). 

Website được xây dựng với định hướng tập trung vào các bài toán thực tiễn của doanh nghiệp và nền tảng pháp lý vững chắc, thay vì chỉ đơn thuần là các quy định lý thuyết.

## 🌟 Điểm nổi bật (Features)

*   **Thiết kế Premium:** Giao diện tối (Dark Mode) sang trọng kết hợp hiệu ứng kính mờ (Glassmorphism) và tone màu Vàng Gold - Đỏ Burgundy - Đen.
*   **Hiệu ứng mượt mà:** Trải nghiệm cuộn trang (Smooth Scroll), hoạt ảnh xuất hiện (AOS), và con trỏ chuột tùy chỉnh (Custom Cursor).
*   **Gallery & Lightbox:** Thư viện ảnh dạng lưới (Masonry) hỗ trợ xem ảnh toàn màn hình và thao tác vuốt trên thiết bị di động.
*   **Music Player:** Tích hợp trình phát nhạc nền với hiệu ứng tăng/giảm âm lượng tinh tế (Fade in/out).
*   **Responsive 100%:** Hiển thị hoàn hảo trên mọi thiết bị từ Desktop, Tablet đến Smartphone.
*   **Tối ưu hóa (No Framework):** Toàn bộ mã nguồn sử dụng HTML5, CSS3 và Vanilla JavaScript thuần, không phụ thuộc vào Bootstrap hay thư viện UI nặng nề.

## 🛠 Công nghệ sử dụng

*   **Cấu trúc:** HTML5 (Chuẩn SEO)
*   **Giao diện:** CSS3 (CSS Variables, Flexbox, CSS Grid, Keyframes Animation)
*   **Tương tác:** JavaScript (ES6)
*   **Triển khai:** GitHub Pages

## 📂 Cấu trúc thư mục

Dự án tuân thủ cấu trúc phân chia module rõ ràng:
- `index.html`: Cấu trúc nội dung chính.
- `css/`: Chứa các file định dạng (`style.css`, `responsive.css`, `animation.css`).
- `js/`: Chứa các kịch bản tương tác (`main.js`, `gallery.js`, `countdown.js`, `music.js`).
- `assets/`: Lưu trữ tài nguyên tĩnh như hình ảnh, âm thanh, logo.
